### 带宽标注：峰值200M和固定5M是两种东西

官方页面上，轻量这台标的是“峰值200M带宽”，u1企业机标的是“5M独享带宽”。峰值是最高能触达的速率，不保证任何时刻都跑满；固定带宽是配给你的确定量，5M对应下载上限约625KB/s。图片、视频多的站点，两种都建议再套一层CDN。 running企业业务时，固定带宽的可预期性往往比峰值数字更值钱。

这是很多文章没写清楚的一点。u1那台199元/年是企业专享，实名认证必须是企业信息，个人认证账号买不了，老企业用户倒是可以买。个人用户的对应选择就是轻量或e实例。

### 弹性：轻量不能升降配，ECS可以

轻量应用服务器买完是固定配置，后期不能升降配；ECS属于完整的弹性体系，业务长大后可以随时调整规格。确定这台机器“一次配好用到报废”，轻量没问题；预期业务会变化，ECS更稳妥。

## 常见问题

**个人用户能买199元/年的u1吗？**
不能。这台机器要求实名认证为企业信息，老企业用户可以买，个人认证账号无法下单。个人用户对应轻量9.9元/月或199元/年，以及e实例标准价。

**第二年续费要多少钱？**
u1企业机官方标注续费不涨价，仍是199元/年。e实例标准年价440.64元，三年972元。轻量这台的续费价没有统一公开，下单前在订单确认页核对。

**要不要直接上2核8G或4核8G？**
看瓶颈在哪。数据库缓存、多个常驻服务这类吃内存的业务，考虑2核8G；并发上不去、CPU先顶满的，加核比加内存有效，对应4核8G。流量再往上，就是负载均衡加多台4核8G的架构了。

**要跑Windows或商业软件呢？**
选Intel平台计算型（如c9i）这类x86实例更稳妥，兼容性和后续升级路径都更顺。
